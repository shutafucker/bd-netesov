# Сервис расписания колледжа

Статическое веб-приложение для просмотра расписания выбранной группы на сегодня и определения текущей пары. Интерфейс адаптирован для телефона и компьютера, автоматически поддерживает светлую и тёмную темы.

## Возможности

- загрузка списка групп из Supabase;
- просмотр занятий выбранной группы на текущий день;
- определение текущей пары, перемены, начала и конца учебного дня;
- запоминание выбранной группы на устройстве;
- понятные состояния загрузки, отсутствия данных и ошибки подключения;
- responsive-интерфейс без frontend-фреймворков и backend-сервера;
- публичный доступ только на чтение с помощью Row Level Security.

## 1. Создание проекта Supabase

1. Зарегистрируйтесь на [supabase.com](https://supabase.com/) и откройте Dashboard.
2. Нажмите **New project**.
3. Выберите организацию, укажите имя проекта и надёжный пароль базы данных.
4. Выберите ближайший регион и дождитесь создания проекта.

## 2. Создание таблиц и тестовых данных

1. В меню проекта откройте **SQL Editor**.
2. Нажмите **New query**.
3. Откройте локальный файл `database.sql`, скопируйте его содержимое в редактор и нажмите **Run**.
4. В разделе **Table Editor** должны появиться таблицы `groups` и `schedule`.

Скрипт можно выполнить повторно: группы не дублируются, а тестовое расписание обновляется по группе, дню и номеру пары. Он добавляет группы «ПО-41» и «ИС-22» и занятия на несколько дней.

## 3. Подключение сайта к Supabase

1. В Dashboard откройте **Project Settings → API**. В обновлённом интерфейсе нужные значения также могут находиться в разделе **Connect**.
2. Скопируйте **Project URL**.
3. Скопируйте публичный **anon/public key**. Если Supabase показывает новые ключи, используйте клиентский publishable key.
4. Откройте `config.js` и замените значения:

```js
const SUPABASE_URL = 'https://ваш-проект.supabase.co';
const SUPABASE_ANON_KEY = 'ваш-публичный-ключ';
```

Публичный ключ можно использовать в браузере только вместе с корректными RLS-политиками. Никогда не вставляйте в сайт `service_role` key: он секретный и обходит Row Level Security.

## 4. Локальный запуск

Запустите HTTP-сервер из корня проекта одним из способов.

Python:

```bash
python3 -m http.server 8000
```

Или Node.js:

```bash
npx serve
```

После команды Python откройте [http://localhost:8000](http://localhost:8000). Открывать `index.html` двойным кликом не рекомендуется: HTTP-сервер точнее повторяет поведение сайта после публикации.

## 5. Изменение расписания

Данные редактируются в **Supabase Dashboard → Table Editor**:

- `groups` содержит названия учебных групп;
- `schedule` содержит номер пары, предмет, время и ссылку `group_id` на группу;
- `day_of_week`: 1 — понедельник, 2 — вторник, 3 — среда, 4 — четверг, 5 — пятница, 6 — суббота;
- время хранится в локальном учебном расписании, например `08:30:00`.

Для одной группы нельзя создать две пары с одинаковыми `day_of_week` и `lesson_number`. Время окончания должно быть позже времени начала.

## 6. Публикация на Vercel

1. Создайте репозиторий на GitHub и отправьте в него проект.
2. В Vercel нажмите **Add New → Project** и импортируйте репозиторий.
3. В **Framework Preset** выберите **Other**.
4. Оставьте Build Command пустой, а Output Directory укажите `.` или оставьте значение по умолчанию для статического проекта.
5. Нажмите **Deploy**.

Дополнительный Node.js backend, переменные окружения и `vercel.json` не нужны. После изменения файлов в GitHub Vercel автоматически создаст новую версию сайта.

## Устранение проблем

### «Добавьте данные проекта»

В `config.js` остались значения `YOUR_SUPABASE_URL` или `YOUR_SUPABASE_ANON_KEY`. Замените оба значения и обновите страницу.

### Группы не загружаются

- убедитесь, что `database.sql` выполнен без ошибок;
- проверьте Project URL и anon/public key;
- убедитесь, что браузер имеет доступ к интернету;
- откройте таблицы в Supabase и проверьте, что RLS-политики `groups_are_publicly_readable` и `schedule_is_publicly_readable` существуют;
- посмотрите техническую ошибку в консоли разработчика браузера.

### Группы есть, но расписание пустое

Проверьте `group_id`, `day_of_week` и текущий локальный день на устройстве. В воскресенье приложение всегда показывает, что занятий нет.

### Изменения не появились после публикации

Убедитесь, что Vercel завершил последнюю сборку, затем обновите страницу без кеша. Данные Supabase загружаются при каждом действии и не требуют нового deploy.

## Будущий Telegram-бот

Схема базы не зависит от веб-интерфейса. В будущем Telegram-бот сможет читать те же таблицы `groups` и `schedule`, фильтруя строки по `group_id` и `day_of_week`. Секрет бота и серверные ключи нужно хранить только на серверной стороне бота, а не в этом статическом сайте.
