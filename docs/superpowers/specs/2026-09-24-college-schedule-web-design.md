# Дизайн веб-сервиса расписания колледжа

## Цель и границы

Создать публичное статическое веб-приложение для просмотра расписания колледжа. Пользователь выбирает группу и может посмотреть все занятия на текущий день либо узнать состояние расписания в текущий момент.

В эту версию не входят авторизация, административный интерфейс и Telegram-бот. Группы и расписание редактируются вручную через Supabase Dashboard. Структура данных остаётся общей и не зависит от веб-клиента, поэтому будущий Telegram-бот сможет читать те же таблицы без миграции схемы.

## Технологии и развёртывание

- HTML5, CSS3 и Vanilla JavaScript без frontend-фреймворков и сборщика.
- Официальный JavaScript SDK Supabase подключается через CDN.
- Supabase является единственным источником групп и расписания.
- Сайт разворачивается как Static Site на Vercel без собственного backend.
- `config.js` содержит только Project URL и публичный anon key. `service_role` key не используется.

## Структура проекта

Обязательные файлы:

- `index.html` — семантическая разметка приложения и подключение скриптов.
- `style.css` — адаптивное оформление, темы и состояния интерфейса.
- `app.js` — загрузка данных, временная логика и рендеринг.
- `config.js` — публичные параметры подключения к Supabase с инструкциями.
- `database.sql` — схема, RLS и демонстрационные данные.
- `README.md` — настройка Supabase, локальный запуск и Vercel.
- `.gitignore` — стандартные локальные и редакторские файлы.

Тесты логики могут находиться в дополнительном каталоге `tests/`; это не добавляет runtime-зависимостей и не меняет статическую архитектуру приложения.

## Интерфейс

Страница оформляется как лёгкое современное системное приложение, вдохновлённое iOS, iPadOS и macOS, но не копирует конкретный продукт Apple.

В верхней части находятся крупный заголовок «Расписание», подзаголовок «Актуальное расписание занятий» и текущая локальная дата. Ниже располагается полупрозрачная панель с выбором группы и двумя равнозначными по размеру действиями: основной кнопкой «Сегодня» и вторичной кнопкой «Сейчас».

Результат выводится в самостоятельной области. Расписание представлено карточками с номером пары, названием предмета и временным интервалом. Текущая пара использует спокойный зелёный индикатор. Перемена, ещё не начавшиеся занятия, завершившийся день, отсутствие расписания и ошибки имеют отдельные лаконичные состояния. Во время загрузки показываются skeleton-карточки.

На мобильном экране содержимое занимает доступную ширину с системными и safe-area отступами. На desktop интерфейс ограничен читаемой центральной колонкой. Высота интерактивных элементов составляет не менее 44 px. Светлая и тёмная темы выбираются через `prefers-color-scheme`; декоративное движение отключается через `prefers-reduced-motion`. Основные элементы имеют видимые hover, active, focus-visible и disabled состояния.

## Поток данных

При загрузке страницы приложение создаёт публичный Supabase-клиент и вызывает `loadGroups()`. Группы запрашиваются из таблицы `groups`, сортируются по имени и добавляются в `<select>`. Выбранная группа сохраняется в `localStorage` и восстанавливается только если она присутствует в актуальном ответе Supabase.

Действие «Сегодня»:

1. Проверяет выбранную группу.
2. Определяет локальный день недели пользователя.
3. Для воскресенья сразу показывает отсутствие занятий.
4. Для дней 1–6 запрашивает строки `schedule` по `group_id` и `day_of_week`.
5. Сортирует ответ по `lesson_number ASC` и отображает карточки.

Действие «Сейчас» использует расписание выбранной группы за текущий день. `timeToMinutes()` переводит время Supabase и текущее локальное время в минуты от начала суток. Чистая функция определения состояния возвращает один из вариантов:

- `current` — текущее время входит в интервал пары, включая обе границы;
- `break` — текущее время находится между занятиями, с данными ближайшей следующей пары;
- `before` — текущее время раньше начала первой пары;
- `after` — текущее время позже окончания последней пары;
- `empty` — занятий в этот день нет.

Каждое действие очищает устаревший результат и блокирует кнопки до завершения запроса. Идентификатор запроса не позволяет более старому ответу перезаписать результат нового действия. Данные из Supabase вставляются в DOM через безопасные текстовые свойства, без интерпретации пользовательского HTML.

## Supabase и безопасность

`database.sql` создаёт таблицы `groups` и `schedule`, внешний ключ `schedule.group_id -> groups.id`, ограничения допустимых значений и индексы для типовых запросов. Для обеих таблиц включается RLS и создаются политики публичного чтения для ролей `anon` и `authenticated`. Политики записи не создаются.

Скрипт содержит идемпотентно добавляемые тестовые данные минимум для групп «ПО-41» и «ИС-22» на несколько дней. Веб-клиент не содержит секретов и никогда не использует `service_role` key.

## Ошибки и доступность

- Незаданные параметры `config.js` дают понятное сообщение о настройке подключения.
- Ошибка сети или Supabase отображается без технических подробностей и предлагает повторить действие.
- При отсутствии групп основные действия отключаются.
- При попытке запуска без группы показывается подсказка, а фокус переводится на `<select>`.
- Пустое расписание отображается как нормальное информационное состояние.
- Статусы загрузки и результаты находятся в области с подходящим `aria-live`.
- Поля имеют связанные подписи, кнопки — понятные текстовые названия, а цвет не является единственным носителем состояния.
- Цвета проверяются на читаемость в светлой и тёмной темах.

## Проверка

Чистая логика времени экспортируется без нарушения работы обычного браузерного скрипта и проверяется тестами без frontend-фреймворка. Тесты покрывают разбор времени, граничные значения текущей пары, перемену, время до первой пары, время после последней пары и пустой день.

Перед завершением выполняются:

- автоматические тесты логики;
- проверка синтаксиса JavaScript;
- проверка обязательной схемы и RLS в SQL;
- запуск через локальный статический HTTP-сервер;
- визуальная проверка при ширине 390 px и на desktop;
- проверка светлой и тёмной темы, клавиатурного фокуса и reduced motion;
- сверка результата со всеми пунктами исходного технического задания.

## Критерии готовности

После добавления Supabase URL и anon key пользователь может открыть сайт, выбрать одну из загруженных групп, увидеть расписание на текущий день и корректное состояние «Сейчас». Все обязательные состояния отображаются понятно, интерфейс адаптируется к мобильному и desktop-размерам, а проект разворачивается на Vercel как статический сайт без дополнительной конфигурации backend.
