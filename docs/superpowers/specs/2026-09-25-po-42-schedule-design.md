# Расписание группы ПО-42

## Цель

Добавить третью группу `ПО-42` с повторяющимся недельным расписанием из предоставленного изображения. На сайте и в Telegram-боте показывать предмет, преподавателя, кабинет и время.

## Данные

В `public.schedule` добавляются nullable-поля `teacher_name text` и `room text`. Они nullable, поэтому существующее расписание ПО-41 и ИС-22 продолжает работать без обязательного заполнения новых значений.

ПО-42 получает четыре пары с понедельника по пятницу. Суббота остаётся без занятий. Недельное расписание повторяется бессрочно по существующему `day_of_week`.

В понедельник используются интервалы:

1. 08:30–09:50
2. 10:40–12:00
3. 12:40–14:00
4. 14:10–15:30

В остальные дни используются интервалы:

1. 08:30–10:00
2. 10:10–11:40
3. 12:20–13:50
4. 14:00–15:30

Пятые интервалы сохранять не требуется, потому что на изображении нет пятой пары. Если она появится позднее, для понедельника используется 15:40–17:00, для остальных дней — 15:40–17:10.

Предметы, преподаватели и кабинеты переносятся с изображения в порядке строк. Значения для разделённых подгрупп сохраняются одной строкой через `/`. Отсутствующий кабинет остаётся `null`.

## Отображение

Сайт добавляет преподавателя и кабинет в карточку пары, когда соответствующее значение заполнено. Пустые значения не создают пустых строк.

Telegram-бот добавляет строки `Преподаватель: ...` и `Кабинет: ...` в расписание на сегодня и сведения о текущей или следующей паре. Для старых записей без этих данных формат остаётся аккуратным.

## Проверка

- SQL повторно запускается без дублей и добавляет группу ПО-42.
- ПО-42 имеет четыре пары на каждый день с понедельника по пятницу и не имеет субботних записей.
- Понедельник и остальные дни используют разные интервалы.
- Сайт и бот выводят преподавателя и кабинет только при наличии.
- Существующие тесты и расписание ПО-41/ИС-22 остаются рабочими.
