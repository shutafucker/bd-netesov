# PO-42 Schedule Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add group ПО-42 with its recurring weekly schedule and display teacher/room details on the website and in Telegram.

**Architecture:** Extend schedule rows with optional `teacher_name` and `room` text fields so existing groups remain compatible. Seed ПО-42 by weekday using its day-specific time intervals, then carry the optional fields through the existing browser and bot rendering paths.

**Tech Stack:** PostgreSQL/Supabase, Vanilla JavaScript, Supabase Edge Functions TypeScript, Node.js test runner.

## Global Constraints

- ПО-42 repeats weekly from Monday through Friday; Saturday and Sunday are empty.
- Monday and Tuesday–Friday use the exact intervals approved in the specification.
- Teacher and room are optional for compatibility with existing rows.
- Split subgroup values use `/` in a single display string.
